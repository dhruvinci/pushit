# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Pushit TV website: a static Astro 7 site (Node 22) for an Indian underground-metal video channel. Each "tape" is a Markdown file; full videos are YouTube embeds; Instagram footage appears as self-hosted stills. Deployed on Vercel; production origin is `https://www.pushit.tv`.

## Commands

```sh
npm install                  # if it hangs with ETIMEDOUT: NODE_OPTIONS=--dns-result-order=ipv4first npm install
npm run dev                  # http://localhost:4321
npm run build                # static site → dist/ (this is also the only check; there are no tests or linter)
npm run preview
npm run import-media         # rebuild public/media + src/data/media.json (needs ffmpeg, jq, curl, and research/)
.venv/bin/python scripts/make-brand.py   # regenerate favicons + per-page OG images in public/og/ (Pillow + node_modules fonts)
```

- After editing `src/lib/remark-clip.mjs` (or `media.mjs` output it uses), delete `.astro/` and `node_modules/.astro/` before building — Astro caches rendered Markdown.
- Re-run `make-brand.py` after adding a tape or a `spotted` entry; pages reference `/og/tapes/<id>.jpg`, `/og/spotted/<id>.jpg`, etc., which must exist.
- `research/` (Instagram/YouTube scrapes, raw video cache) is gitignored and only needed for `import-media`.

## Architecture

**Content collections** (`src/content.config.ts` is the schema source of truth):
- `episodes` — `src/content/episodes/*.md`. Frontmatter references `spotted` ids; `youtube[].chapters` become a clickable setlist.
- `spotted` — `src/data/spotted.json` (bands, artists, venues, promoters, labels).
- `work` — `src/data/work.json` (music videos; references `spotted` and optionally a `bts` episode).

**Episode helpers** (`src/lib/episodes.ts`): `getEpisodes()` returns episodes newest-first with a derived tape number (`PTV-001` = oldest by filming `date`), so adding an older tape renumbers later ones. Also the `(DD.MM.YY)` date `stamp`, series labels/codes, `runtime`, `coverSrc`.

**Series list is duplicated** in three places that must stay in sync: `SERIES` in `src/content.config.ts`, `SERIES` metadata in `src/lib/episodes.ts`, and `SERIES` in `scripts/make-brand.py`.

**Media pipeline** — pages never touch media files directly, only the manifest:
- A clip ref is `"<instagram shortcode>/<carousel index>"` (e.g. `DaVcpQwj-3d/03`) → `public/media/ig/<ref>.jpg`.
- `src/lib/media.mjs` reads `src/data/media.json` (generated by `scripts/import-media.sh`) and resolves refs to still / loop URLs, dimensions, and whether the still is a video frame (then it links to the Instagram post instead of hosting video). Unknown refs throw at build time.
- Only `heroClip` refs get a hosted ~10 s silent loop (`public/media/loops/`); start offset defaults to 1 s, overridden in `scripts/loop-starts.txt`.
- `PUBLIC_MEDIA_BASE` env var prefixes all media URLs (for serving from a bucket instead of `public/`).

**`::clip` Markdown shorthand** — `src/lib/remark-clip.mjs` (registered in `astro.config.mjs`) turns a paragraph that is exactly `::clip <ref> ["caption"]` into a `<figure>`; consecutive clips are grouped into a `.clip-sheet` contact sheet.

**Site URL** (`astro.config.mjs`): `SITE_URL` env → Vercel preview URL on preview deploys → `https://www.pushit.tv`. Canonical and OG image URLs must be absolute and match the real host or link previews (WhatsApp) break. `trailingSlash: 'always'` — internal links use trailing slashes.

**Layout/styling**: every page wraps `src/layouts/Base.astro` (meta, OG, JSON-LD, nav, fonts via `@fontsource`). Design tokens and shared styles live in `src/styles/global.css`. `TapePlayer.astro` / `YouTube.astro` are poster-first: nothing loads from YouTube until play.

**Site-wide constants** (name, socials, contact email) in `src/site.ts`; setting `email` enables the enquiry form on `/work`.
